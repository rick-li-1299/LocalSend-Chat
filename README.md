# LocalSend Chat

非官方 Windows 局域网聊天版，基于 [LocalSend](https://github.com/localsend/localsend)，保留 Apache 2.0 许可证及原作者版权。

[下载最终 Windows 版](https://github.com/rick-li-1299/LocalSend-Chat/releases/latest)

- 设备间聊天、群聊、文字与文件传输。
- 本地聊天记录、搜索、备注、置顶及明确授权的可信设备接收。
- 双击本机名称直接编辑，回车保存、Esc 取消。
- 启动时检查 GitHub 新版，点击“立即更新”下载、校验并重启。

仓库当前只维护 Windows 聊天版所需源码、依赖、测试及打包流程。旧版本运行包、Flutter/Rust 工具链、构建缓存和个人聊天数据不纳入发布。

普通使用请选择 Release 中的 EXE 安装包或 ZIP 便携包其中一种。[构建与更新说明](README_CHAT.md)。
